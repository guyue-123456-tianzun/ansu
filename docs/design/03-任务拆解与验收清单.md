# 5. 90 秒答辩剧本（三档）

> 原文 §9.1 在 55–70s 塞入“3 分钟微课 + 5 题”，15 秒不可能播完。必须三选一，并明示。
> 数字固定：314、23:10:03、812W、PF 0.998、阶跃 780W、持续 3.2s、阈值 400W。

## 5.0 三档选择

| 档 | 做法 | 优点 | 风险 | 建议 |
|---|---|---|---|---|
| A 申诉版 | 90 秒只走申诉 → 复核 → 恢复 → 简报 | 最稳，20 秒讲完申诉 | 少讲“学习”钩子 | **保底** |
| B 速通版 | 申诉 + 学习“速通”：1 页图文 + 5 题快答（明示演示速通） | 保留原文完整叙事 | 5 题需 10–12 秒，节奏紧 | **目标** |
| C 预完成版 | 展示“已通过”的学习记录，只演示恢复 + 信用 +3 | 最快、最稳 | 过程不完整，需诚实说明 | 时间不够时用 |

## 5.1 A 申诉版（保底，90 秒）

| 时间 | 画面/动作 | 口播 | 兜底 |
|---|---|---|---|
| 0–8s | 大屏全景 | “宿舍用电安全最大的问题不是看不见，而是看见了学生不认、宿管说不清、学校留不下痕。我们做的是 B2B2C 共治平台。” | 无 |
| 8–18s | 选 314 → 注入 800W 阻性 | “管理端选中 314，注入一台 800W 热得快。3 秒内曲线阶跃、状态灯变橙。” | 若未变色，点重置再注入 |
| 18–28s | 学生 H5 弹窗 → 告警详情 | “学生手机 1 秒内收到提醒。不是甩一个红点，而是告诉他：功率从 32W 阶跃到 812W，PF 0.998，持续 3.2 秒。” | 第二台手机/录屏 |
| 28–38s | 证据曲线 + 三段式 | “发生了什么、为什么判定、现在怎么做。规则、阈值、版本都在证据包里。” | 刷新一次 |
| 38–48s | 点“提交申诉” → 选设备故障 → 陈述 | “学生认为是电脑电源误判，提交申诉。证据包自动附带，宿管端出现 24 小时 SLA 待办。” | 用预置申诉 |
| 48–60s | 切宿管端 → 申诉工作台 → 通过 | “宿管看同一份证据，点通过。用电恢复，扣分撤销，学生收到通知。” | 用预置待办 |
| 60–72s | 学生端状态恢复/信用 | “注意：恢复用电和撤销违规是两件事。30 秒回落只恢复用电；申诉通过才撤销扣分。” | 截图 |
| 72–84s | 大屏 → 生成日报 | “一键日报：态势、违规、申诉、建议，数字与前面完全一致。” | 预生成模板 |
| 84–90s | 收尾 | “我们不是抓违规，而是让每一次提醒都有回应、有学习、有闭环。学校少出事，学生少对抗，宿管少写材料。” | 无 |

## 5.2 B 速通版（目标，90 秒）

前 40 秒同 A；40–55 秒申诉；55–70 秒学习；70–85 秒简报；85–90 秒收尾。

| 时间 | 画面/动作 | 口播 | 兜底 |
|---|---|---|---|
| 40–55s | 学生提交申诉 → 宿管待办 | 同 A 的 38–60s，压缩口播 | 预置申诉 |
| 55–70s | 切“首次违规”预置页 → 学习“速通” | “首次违规可以学习恢复。演示模式跳过视频，直接 5 题；80 分通过，恢复用电，信用 +3。” | 点“演示作答”自动填；界面标“演示” |
| 70–85s | 生成日报 | “日报的违规、申诉、学习数字与前面一致。” | 预生成模板 |
| 85–90s | 收尾 | 同 A | 无 |

> 关键：B 的 55–70s 必须提前把“5 题页面”预加载好；不要现场等视频。若 5 题超过 12 秒，立即切 C。

## 5.3 C 预完成版（兜底，90 秒）

55–70s 直接打开一条“已通过”的学习记录，展示：
- 课程名、分数 80、证书 ID；
- 点击“恢复用电” → 状态 normal、信用 +3；
- 口播：“学习过程已提前完成，现场演示恢复结果；完整 5 题可在全功能演示里看。”

> 不要假装刚刚播完 3 分钟视频；诚实说明反而加分。

## 5.4 学习全功能演示（5–8 分钟，非 90 秒）

1. 切“首次违规”场景 → 学生告警详情 → 点“去学习”。
2. 明示“演示速通：跳过 3 分钟视频，保留 5 题测验”。
3. 5 题作答（可点“演示作答”自动填，但界面标注“演示”）。
4. 80 分 → 恢复 → 信用 +3。
5. 切第 3 次违规 → 锁定 3h → 学习不能解锁。

## 5.5 讲解三条硬规则

1. 数字前后一致；不切乱 run。
2. 每点一个按钮，说清“为什么点”。
3. 出故障先降级，不现场 debug。

# 8. 降级与现场处置

| 故障 | 现场动作 | 话术 |
|---|---|---|
| 注入后无告警 | 检查 run/阈值；点重置再注入；仍失败切录屏 | “演示环境有状态残留，我们重置 run 再走一遍。” |
| 学生端打不开 | 第二台手机/浏览器/录屏 | “同一套 H5，换设备即可。” |
| Python 挂 | Java 模板；界面标“模板模式” | “AI 是增强，不是单点依赖。” |

| 数字对不上 | 停演示，重置 run，重走 | “四个模块读同一个 run_id，重置后一致。” |
| 时间不够 | 直接跳到申诉通过+简报 | “核心闭环是提醒—申诉—恢复—复盘。” |
