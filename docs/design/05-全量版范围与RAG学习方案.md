### 6.4 认证表（第 23 张）

```sql
CREATE TABLE auth_refresh_token (
  id          BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  user_id     BIGINT UNSIGNED NOT NULL,
  token_hash  CHAR(64) NOT NULL,
  expires_at  DATETIME(3) NOT NULL,
  revoked_at  DATETIME(3) NULL,
  user_agent  VARCHAR(255) NULL,
  ip_hash     CHAR(64) NULL,
  created_at  DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  PRIMARY KEY (id),
  UNIQUE KEY uk_refresh_hash (token_hash),
  KEY idx_refresh_user (user_id),
  KEY idx_refresh_expire (expires_at),
  CONSTRAINT fk_refresh_user FOREIGN KEY (user_id) REFERENCES user_account(id)
    ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;
```

- 登录：用户名/密码 → 短期 JWT（30–60 分钟）+ 刷新令牌（HttpOnly Cookie，7–30 天）。
- 刷新：轮换刷新令牌；旧令牌撤销；检测重放。
- 演示身份切换：仍保留，仅 `demo` profile；不写刷新令牌。
- 密码：BCrypt/Argon2；不存明文；登录限流；失败锁定。

## 七、架构（全量）

```text
Vue3 管理端/学生H5/维修端
        │ 只连 Java /api
        ▼
Java 17+（推荐 21）+ Spring Boot 3（业务事实/事务/权限）
  ├─ MySQL 8：23 表
  ├─ AiClient ──► Python 3.11 + FastAPI（AI sidecar）
  │                 ├─ /ai/explain /ai/qa /ai/briefing /ai/simulate
  │                 ├─ /ai/rag/ingest /ai/rag/search
  │                 ├─ /ai/rag/generate-material /ai/rag/generate-quiz
  │                 └─ ChromaDB（本地持久化向量）
  │                      + BGE-M3 embedding + BGE-reranker
  │                      + GLM-4-Plus（默认）/ 本地 Qwen（可选）
  └─ Ingestion Worker（Python，DB 任务表轮询）
        └─ 解析 PDF/DOCX/TXT/MD、OCR、分块、嵌入、索引
```

**为什么不是微服务**：仍然是两个主进程 + 一个可选 worker + 一个嵌入式向量库；没有注册中心/网关/MQ。RAG 是 Python sidecar 的能力扩展，不是第三套后端。

**LLM 模式（已选 RG01 = GLM-4-Plus）**：

- 生成默认调用 GLM-4-Plus（OpenAI 兼容接口），无需 GPU；嵌入/重排仍本地部署。
- 外部 LLM 只接收**检索到的 top-k 片段**，不传整份规定、文件名、上传人；请求带 `request_id`，记录用量与延迟。
- 片段发送前可做敏感信息脱敏；可配置 `RAG_LLM_MODE=local` 切换本地 Qwen2.5-14B/32B，实现数据不出校。
- 若学校要求“规定不出校”，直接切本地模式；接口与返回结构不变。

### 9.2 RAG 学习

- 上传 3 份真实规定（PDF/DOCX/扫描件各 1），解析/分块/检索可用。
- 每份规定至少生成 5 题；100% 带来源引用；人工审核后可发布。
- 学生端不泄题；提交后显示解析与引用；重试用 B 卷。

- 详见 `06` 第 17 节。

### 9.3 全量非功能

- 权限：六角色矩阵全过；学生越权 403。
- 审计：所有写操作可追溯；知识库/题目发布有审计。
- 性能：大屏首屏 ≤2s；曲线 ≤500ms；RAG 检索 p95 ≤1s；出题 ≤30s；解析 100 页 ≤5min（CPU）。
- 可用性：LLM/向量库/嵌入模型任一故障，核心业务与静态学习仍可用。
- 安全：上传类型/大小/路径校验；文档内容不执行指令；日志脱敏。
- 隐私：不采集摄像头/人脸/行踪；信用到宿舍；规定文档仅校内可见。
