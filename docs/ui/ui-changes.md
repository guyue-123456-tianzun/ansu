# UI 变更日志

## R1 · 2026-11-12 · 共享层 + 已确认规则/文案

### 范围

- 新增 `src/styles/tokens.css`：间距、字号、颜色、圆角、阴影、断点；全局 `box-sizing`、focus-visible、reduced-motion。
- `main.ts` 引入 tokens；覆盖 Element Plus 主色/语义色/圆角（只改变量，不改依赖）。
- 登录页文案改为 B：
  “演示环境：选择角色进入；仅使用演示数据，正式版将接入学校统一身份认证。”
- 信用分上限 120 → 100：
  - `thresholds.yaml` `credit.max: 100`
  - 后端所有 `Math.min(120, ...)` → `Math.min(100, ...)`
  - Flyway `V3__credit_cap_100.sql` 修改 `dorm`/`credit_ledger` 检查约束
  - 学生端显示 `/100`，文案改为“加分到 100 为止”
- 学生端全宽：
  - `HomeView`：移除 430/980 上限，100% 宽度；≥900 双列；桌面 32px 边距
  - `AlertDetailView` / `LearningView` / `AppealsView`：移除 430/900 固定上限，全宽 + 32px 边距
  - 学习页选项改为整行卡片（42px 高、左对齐、选中高亮）
- 补 1920×1080 基线：`docs/ui/screenshots/.../1920/...`
