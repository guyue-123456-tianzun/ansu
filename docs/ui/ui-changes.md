## R2 · 2026-11-12 · 管理大屏响应式 + 错误/加载态

### 改动

- 管理大屏断点：
  - `≥1200`：三栏（左 250 / 中自适应 / 右 310），图表填满高度
  - `900–1199`：两栏（左 230 / 中自适应），告警栏下移全宽
  - `<900`：单列；指标 2 列；寝室列表最高 280 可滚动；图表 240
  - `<600`：指标 2 列，最后一张跨 2 列；按钮最小高 36
- 指标卡：`minmax(0,1fr)` + `clamp` 字号 + `nowrap`，修复 768/1024 文字竖排/截断
- 顶栏：允许换行；品牌标题不竖排；操作按钮可换行
- 错误/加载态：
  - 请求失败：红色横幅“数据加载失败：… + 重试”
  - 首次加载：蓝色横幅“正在加载安全态势…”
  - 指标未加载显示 `—`，不再伪装成 0
- 告警类型中文化：`resistive→阻性`、`overload→总功率`、`leakage→漏电`、`temp→温度`
- 图表：阈值从当前告警取（不再硬编码 500）；右侧留 76px；标签显示 `500W` 不再被裁；x 轴 `hideOverlap`

## R3 · 2026-11-12 · 对比度、触控、状态字典、错误态
